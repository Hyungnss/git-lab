# GIT 학습 메모

## 오늘의 목표

- 현재 폴더를 확인한다.
- 파일을 작성하고 저장한다.
- 변경 이유를 기록한다.

## 오늘 배운 내용 정리

- Git add란 작업 폴더에서 수정한 파일을 스테이징 영역에 올리는 것 (add 시점의 내용이 올라감)
- Git commit이란 스테이징 영역에 올린 내용을 스냅샷으로 .git 저장소에 저장하는 것 (메시지와 해시가 붙어 이력으로 남음)

## 학습 소감

- 오늘 git에 대해서 알 수 있는 시간이었고, 헷갈렸던 restore와 restore --cached에 대해 이해할 수 있는 시간이 된 것 같다.
